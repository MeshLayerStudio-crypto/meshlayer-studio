C. Data

Bambu Lab filament color table: NOT bundled. Only when the user picks a Bambu Lab printer plate and agrees, the program reads the
filament color file of the user's own installed Bambu Studio (filaments_color_codes.json); if Bambu Studio is not installed it can download
that single file (about 230 KB) from Bambu's public GitHub repository to the user's own data folder, and keeps a cache there.
The program does not distribute or forward Bambu's data. Bambu Lab and Bambu Studio are trademarks of their owner; this product is not affiliated
with or endorsed by Bambu Lab (Bambu Studio is AGPL-3.0).

core\printer_caps.py - number of filament slots per printer model: facts compiled by the author from public pages, with a source and a
confidence note for each entry; not copied from any vendor or open-source data file. Not official specifications.

"3MF" is a format by the 3MF Consortium (specification under its own terms).
The paint_color encoding read/written by this product follows the format used
by Bambu Studio / OrcaSlicer / PrusaSlicer, which are separate projects.

F. OpenSCAD (optional external program)
-----------------------------------------------------------------------
OpenSCAD (https://openscad.org) is licensed under GPL-2.0-or-later. It is NOT bundled, linked or modified:
the user installs it separately (or unzips a Development Snapshot into third_party/openscad-nightly/) and
this product runs it as a separate process (command line) on .scad files the user chooses. .scad files are
third-party works and keep their authors' licenses. Several installations can coexist; this product never
replaces or modifies one. Tested 2026-10-27 with the stable 2021.01 and the Windows x64 snapshot 2026.10.25.

Engine note (OpenSCAD versions): as of 2026-10 the newest official stable release of OpenSCAD is still
2021.01 (CGAL geometry backend only). The Manifold backend (much faster) is available in the Development
Snapshots (not experimental since the 2024.09.28 snapshot). This product probes the installed OpenSCAD
(--version, --help) and runs a small verification model once before it executes any real job.

G. Gridfinity
-----------------------------------------------------------------------
"Gridfinity" is a modular storage system designed by Zack Freedman. This product is not affiliated with or
endorsed by him. The "Gridfinity bin (native engine)" customizer is original code written for this product
from the publicly documented dimensions (42 mm pitch, 7 mm height unit, base and stacking-lip profiles);
no code was copied from other implementations. After it was written, several dimensions were cross-checked
against the constants published in Gridfinity Rebuilt (below) and adjusted to match them (stacking-lip
profile, 1.2 mm lip support, 3.55 mm visible lip height); these are dimensions, not code.
